## Математика
600 синтетических точек возраста и дохода взяты без изменений из актуального кейса JTI. Не хранят персональных данных. Стандартизация по среднему и популяционному стандартному отклонению. Для k=1…8: Ллойд, 20 воспроизводимых инициализаций k-means++, один дополнительный старт от предыдущего разбиения с новым центром в самой дальней точке. Выбирается минимум WCSS. Остановка при квадрате сдвига менее 1e-18 или 300 итерациях. Центры упорядочены по возрасту для устойчивой легенды; цвета между разными k не означают идентичность сегментов.

WCSS и средний силуэт рассчитываются в браузере по тем же исходным данным. Попарные евклидовы расстояния для силуэта учитывают стандартизацию; у одиночной точки силуэт 0, для k=1 не определён. Кривая локтя — эвристика. Число 2 не навязывается алгоритму, но в этих данных два облака заданы генератором. При k=2 WCSS≈75.63 против1200 при k=1, средний силуэт≈0.844 — максимум среди2…8.

## Проверки
`python3 tests/test_clusters.py` при локальном сервере8834; `LAB_BASE` позволяет проверить опубликованный сайт. WCSS пересчитан NumPy, силуэт — sklearn; проверены средние центров, назначение ближайшему центру и монотонность WCSS для всех k. Браузер проверяет k1…8, число крестиков, неизменность точек, три вкладки, работу прежнего прогноза и гармоник, мобильную ширину и ссылку на метод. Повторно прошёл тест гармоник. Просмотрены компьютерная и мобильная версии.
