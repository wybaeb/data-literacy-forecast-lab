# Правила интерфейса тренажёров

- Перед следующей порцией пользовательских правок сохраняй текущую версию в Git и пушь разрешённую рабочую ветку. Не сливай main без отдельного указания.
- В пользовательском интерфейсе и раскрываемых описаниях не упоминай названия/внутренние обозначения других курсов. История происхождения допустима только во внутренних материалах Git. Научные источники и общепринятые термины сохраняй.
- Легенды показывают образец линии или символ рядом с названием, а не текстовые обозначения цветов.
- Общая навигация должна сохраняться на всех страницах тренажёров; прямые ссылки на существующие страницы остаются рабочими.
